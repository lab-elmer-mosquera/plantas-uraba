# Plantas de Urabá

Un sistema de captura, organización y preservación del conocimiento que estoy generando sobre la flora de Urabá. La investigación botánica es el dominio; el diseño de sistemas es el medio y, en cierto modo, también el fin: aprender a construir sistemas útiles, trazables y sostenibles mientras hago investigación real.

## Estructura del proyecto

```

plantas-uraba
├── _docs_plantas-uraba
│   ├── ard/              # Decisiones y documentación del proyecto
│   ├── req/              # Requisitos y especificaciones del proyecto / formales de historias de usuario (scrum)
│   ├── vision/           # Visión general del proyecto
│   └── sprints/          # Ciclos de planeación y desarrollo de requisitos
├── datos.js              # Datos del catálogo (categorías, especies e imágenes)
├── desk/                 # Espacio de trabajo (betas/spikes)
├── build/                # Entorno de producción (deplegado en netlify)
└── index.html            # página de inicio (enlazada a los elementos del build)

```
