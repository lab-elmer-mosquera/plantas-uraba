# [ADR-001] Selección del Modelo de Datos para Especies

## Contexto

El proyecto necesita almacenar información taxonómica, imágenes, fuentes y resultados de investigación de manera que sea fácil de consultar y mantener. Se necesita una estructura que permita la trazabilidad de cada dato.

No hay un presupuesto definido para este proyecto, al tratarse de un proyecto de investigación abierto.

## Decisión
Archivos JSON/JS en el Repositorio: Los datos no van a modificarse con frecuencia, y la cantidad de datos es relativamente pequeña.

## Alternativas evaluadas
1.  **Base de Datos Relacional (PostgreSQL)**: Robusto, pero añade complejidad de backend.
2. **Base de Datos Relacional (sqlite)**: Ligero, pero no hay presupuesto para el backend.
3. **Firebase**: Con capa gratuita, pero dada la pequeña cantidad de datos es inviable.
